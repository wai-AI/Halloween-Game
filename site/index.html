Haunted Terminal: Session 07

Команди
ls [шлях]
Переглянути файли і папки
ls -a [шлях]
також приховані
cat <шлях>
прочитати файл
cd <шлях>
перейти в папку
cd ..
на рівень вище
echo <слово>
вивести слово
check <відповідь>
перевірити відповідь
notes
загадка й записи
hint
підказка до загадки
guide
Як грати й користуватися командами

Приклад:
ls /sessions
cat /sessions/session_07.log

Текст у <…> замінюй своїм значенням без дужок. [шлях] — необов’язковий.

Шлях, що починається з /, працює з будь-якої папки. Решта — від поточної.

Tab — доповнити команду або шлях.
↑ / ↓ — історія команд.
