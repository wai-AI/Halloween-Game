### Вимірювання верстки у фінальній версії

Числа отримано з DOM браузера. Координата нижньої межі поля вводу відраховується від верхнього краю iframe.

| Розмір iframe | Ширина вмісту / scrollWidth | Висота сторінки | Нижня межа поля вводу |
| --- | --- | --- | --- |
| 320 × 720, embed | 320 / 320 px | 720 px | 649 px |
| 390 × 844, embed | 390 / 390 px | 844 px | 773 px |
| 390 × 340, embed | 390 / 390 px | 340 px | 281 px |
| 320 × 860, звичайний режим | 305 / 305 px | Сторінка може прокручуватися | 729 px |

У embed немає зайвого прокручування всієї сторінки; прокручується сам вивід. Горизонтального переповнення в цих розмірах немає. Також оглянуто tablet-iframe 768 × 800 та звичайний широкий інтерфейс.

## Межі перевірки

- Мобільні розміри перевірено через реальні вкладені iframe та CSS media queries у Chrome. Фізичні iOS/Android-пристрої, Safari, Firefox і фактична екранна клавіатура не тестувалися. Висота 340 px перевіряє малу доступну область, але не підміняє тест на телефоні.
- Інтервал нагадування Тика перевірено автоматично з керованим часом. Окремий десятихвилинний браузерний тест двох нагадувань не проводився.
- Обмеження localStorage у браузері перевірено sandbox із непрозорим origin та inline-копією коду. Для завантаження зовнішніх ресурсів у суворий sandbox без `allow-same-origin` також потрібні сумісні заголовки хостингу. У звичайному iframe гра працює без такої вимоги.
- GitHub Actions підготовлено за офіційною документацією; реальний deployment не запускався, оскільки репозиторію не надано.
- Редактор дописів і опублікований iframe саме на DOU не тестувалися.
- Повної дослівної копії попереднього сценарію немає. Межі відновлення та доповнення текстів описані в `scenario.md`.
